# Style Guide — ICT Quest

## Feel
Bold, playful, game-like — visually inspired by wayground.com: a dark, energetic look with hot-pink actions, so learning feels like a game rather than homework.

## Colors (the Wayground-inspired theme)
- **Background:** deep plum `#2B1B33` (whole page), lighter plum `#3A2647` for cards.
- **Primary / actions:** hot pink `#FF2E7E` (buttons, headings, unlocked borders); hover `#D91E66`.
- **Accent / secondary buttons:** cream `#F7F1E3`.
- **Success:** green `#3DDC84` (correct answers, completed missions, stars state).
- **Warning / hints:** amber `#FFB64D`.
- **Text:** cream `#F7F1E3` on dark; secondary text muted lavender `#C9B8D4`; borders `#553B66`.
- All text is light-on-dark; contrast checked for readability.

## Typography
- System font stack (fast, works offline): `-apple-system, "Segoe UI", Roboto, Arial, sans-serif`.
- Big, bold headings: the app title is extra-bold (800) pink; body text ≥ 16px, buttons ≥ 18px bold.

## Layout
- **Mobile-first:** one column on phones; content max-width ~640px centered on desktop.
- Big rounded buttons (min 44px tall) with 10px radius.
- Mission cards: plum cards with pink border when unlocked, green when completed, dimmed when locked.

## Game feedback rules
- Correct answer: green highlight + encouragement ("Great job!").
- Wrong answer: amber highlight + a helpful hint — never a scolding message.
- Progress always visible: points line, stars (★/☆), and mission states (Start / Done / Locked).
- Every screen has a clear "← Back to missions" button.

## Accessibility
- Keyboard-navigable (Tab order logical, Enter activates buttons); visible focus outlines.
- Light-on-dark contrast meets WCAG AA for body text.
- Icons always paired with a text label.
- Works on small phone screens and large desktop monitors.

## Language
Simple English, short sentences. Unknown computer terms are explained the first time they appear.
